# MVP 验证记录

验证日期：2026-10-13。

## 核心测试

`npm run check` 和 `npm test` 通过，13 个 Node 内置测试覆盖：

- 三种切分方法的完整覆盖、长度上限及原文位置。
- Unicode emoji、CRLF、空白和无标点文本。
- 固定切分的重叠与非法参数。
- 余弦相似度、负分、并列排序和异常向量。
- API 地址标准化，拒绝带认证信息的 URL。
- 乱序向量响应、重复编号和维度不一致。
- Bearer 请求格式、批次顺序、进度和取消。
- HTTP、网络和 JSON 错误，不直接回显服务端响应正文。

## 浏览器验证

使用 Playwright 驱动本机 Edge，桌面 1440×1080、手机 390×844。
19 项检查通过，无页面 JavaScript 异常：

1. 首次打开载入示例并生成 chunk。
2. 点击 chunk 后准确定位原文。
3. 固定切分显示重叠区域，参数改变使旧 chunk 失效。
4. 句子切分不重叠。
5. 粘贴 HTML 不产生可执行文档元素。
6. 非 UTF-8 文件被拒绝。
7. UTF-8 文件正常读取。
8. 没有索引时检索给出明确提示。
9. 连接测试检查有效向量响应。
10. 批量索引正确处理乱序响应。
11. 问题向量与 chunk 向量正确排序。
12. 导出包含实验结果、不包含测试密钥；localStorage 和 sessionStorage 为空。
13. 后续问题只发送一次问题向量请求，复用已有索引。
14. 修改模型清空旧向量及结果。
15. 正在请求时改变切分配置，过时响应不会覆盖当前状态。
16. HTTP 401 提示不回显服务端正文中的测试密钥。
17. 手机界面与设置弹窗没有横向溢出。
18. 刷新后 API Key 清空。
19. 全流程无 JavaScript 页面错误。

## 验证边界

浏览器流程使用仅用于测试的模拟 embedding API，验证的是应用请求、响应处理和状态逻辑，不是模型的中文检索质量。模拟接口不在发布版本中，也不会替代用户配置的真实 API。

未提供真实 API Key，因此尚未验证账号权限、实际模型可用性、额度、真实向量质量及部署后来源的完整跨域调用。用户可通过页面“测试连接”自行完成真实验证。
